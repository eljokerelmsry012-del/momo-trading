SINA PRO — Digital Options + USDT Wallet (حزمة محدثة)
=====================

محتويات الملف المضغوط:
1) index.html: الموقع كامل في ملف HTML واحد، مع واجهة Digital Options واختصارات سريعة للتداول والحساب ومحفظة USDT.
2) supabase_setup.sql: إعداد جداول الحسابات وسجل الصفقات وطلبات الإيداع والسحب.

مهم:
- الموقع يحتوي على حسابات عبر Supabase، وصفقات تجريبية، ونماذج طلب إيداع/سحب USDT.
- الحد الأدنى لطلب الإيداع 5 USDT.
- طلب الإيداع لا يتحقق من البلوكشين ولا يضيف رصيدًا تلقائيًا.
- طلب السحب لا يرسل أموالًا ولا يخصم رصيدًا.
- لا تضع عنوان محفظة وهميًا ولا تطلب من المستخدمين إرسال أموال قبل إعداد نظام إيداع حقيقي آمن.
- الأسعار والصفقات التجريبية ليست تنفيذًا لصفقات مالية حقيقية. بيانات العملات المشفرة قد تُحمّل مباشرة من Binance عند توفر الإنترنت؛ بقية الأسواق محاكاة.

إعداد قاعدة البيانات (إذا لم تكن نفّذت SQL بالفعل):
1. افتح مشروعك في Supabase.
2. افتح SQL Editor.
3. افتح ملف supabase_setup.sql وانسخ محتواه إلى SQL Editor.
4. اضغط Run مرة واحدة.

النشر على الإنترنت:
ارفع index.html إلى خدمة استضافة صفحات ثابتة مثل Netlify أو GitHub Pages. بعد النشر، افتح رابط الموقع واختبر التسجيل وتسجيل الدخول. يحتاج النشر إلى إنترنت لأن الموقع يستخدم مكتبات وخدمات خارجية.

الأمان والحدود:
هذا إصدار تجريبي للواجهة. قبل استقبال أموال حقيقية، يلزم خادم موثوق للتحقق من معاملات البلوكشين، وإدارة أرصدة آمنة، ومراجعة السحب، وإعدادات أمان وامتثال مناسبة. لا توجد ميزة إيداع/سحب حقيقية مفعّلة في هذه الحزمة.


التحديث الحالي:
- شريط وصول سريع إلى Digital Options والحساب ومحفظة USDT.
- مدد انتهاء متعددة للصفقات التجريبية.
- تسجيل الحساب وطلبات الإيداع/السحب متاحة عبر إعداد Supabase الموجود بالملف.
- اختصارات المحفظة تحفظ طلبات مراجعة فقط؛ لا تنفذ تحويلات ولا تتحقق من البلوكشين.
